# SAST Lab (Java)

This lab provides intentionally unsafe Java code to see how SAST tools detect issues (e.g., SQL injection).

Files:
- java/UnsafeSqlExample.java

Try:
- Run a SAST scanner (e.g., Semgrep, Sonar, CodeQL) against "labs/sast/java".
- Identify and discuss the findings. Propose safer patterns (prepared statements, validation).
